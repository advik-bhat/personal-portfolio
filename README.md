# Advik Bhat — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It includes profile sections, project cards, three short learning notes, social links, and a mobile navigation menu.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Alternatively, open the folder in VS Code and use Live Server, or run `python -m http.server 8000` and visit `http://localhost:8000`.

No packages or build tools are required.

## Project structure

```text
acm-portfolio/
├── index.html   # Page content and structure
├── style.css    # Layout, styling, and responsive rules
├── script.js    # Mobile navigation and footer year
└── README.md    # Setup and project notes
```

## Before submitting

- Replace `YOUR_LINKEDIN_URL` with your LinkedIn profile URL.
- Replace `YOUR_INSTAGRAM_USERNAME` in the Instagram link with your username.
- Confirm the project descriptions, technologies, and links are accurate.
- Rewrite the learning notes in your own voice and add details from your own experience.
- Test the layout on desktop and mobile, and check every link.

## Deployment

This is a static site and can be hosted on GitHub Pages, Netlify, or another static hosting provider. For GitHub Pages, push the files to a repository and enable Pages for the main branch and root folder.

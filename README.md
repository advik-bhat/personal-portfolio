# Advik Bhat — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It includes profile sections, project cards, three short learning notes, social links, and a mobile navigation menu.


## 🚀 Demo

**Live Demo:** : https://advik-bhat.github.io/personal-portfolio/


## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Alternatively, open the folder in VS Code and use Live Server, or run `python -m http.server 8000` and visit `http://localhost:8000`.

No packages or build tools are required.

## Project structure

```text
portfolio/
├── index.html   # Page content and structure
├── style.css    # Layout, styling, and responsive rules
├── script.js    # Mobile navigation and footer year
└── README.md    # Setup and project notes
```

05 / NOTES FROM MY JOURNEY

Things I've been learning.

A few short notes about what I've picked up while building and experimenting.

More than just making a website

Building projects with HTML, CSS and JavaScript has taught me that getting something to appear on screen is only the first step. Making it responsive, handling user input and keeping the code organised are what make a project usable. I'm still learning, but I enjoy seeing how small pieces of code come together into something people can actually use.

What building projects teaches you

I've realised that following a tutorial and building something on your own are two very different experiences. When I work on a project, I have to make decisions about its layout, functionality and structure instead of simply following instructions. I still run into problems, but working through them helps me understand the code better.

Exploring AI beyond the hype

Working on AI-related projects has made me curious about what happens behind the scenes. A model's output might look convincing, but that doesn't automatically make it accurate. I'm interested in understanding how data, model choices and evaluation affect the results, rather than treating AI as a black box that magically produces answers.
